## Overview

Published when a CI test trip is created — for example, when the trip is created in ATMS — before it's ready or
started. Requires the shared trip fields plus a `date` field (the calendar date the trip was created, `YYYY-MM-DD`).

:::warning
**Worth confirming before this goes live**

`citest/base.schema.json` also requires `external_trip_id`, `order_number`, `log_id`, `vo_ticket`, and `asset` on
every leaf event including this one. `log_id`'s format embeds a timestamp that reads like it's generated when the
test actually runs — if that (or any of the other trip fields) isn't actually known yet at trip-creation time,
requiring it here may be too strict. Confirm with the producer before relying on this schema as-is.
:::
