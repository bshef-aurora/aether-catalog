## Overview

The base `detail-type` for CI test assessments. Only `created_by`, `result`, and `description` are enforced;
everything else — including a custom field a producer decides to add — is allowed but not schema-guaranteed
(`additionalProperties: true`).

:::warning
**Known gap: no trip fields on assessment events**

Unlike every `citest.*` event above, assessment events do **not** carry the shared trip fields (`atms_id`,
`external_trip_id`, `vo_ticket`, etc.) — `citest/assessment/base.schema.json` only extends the common envelope, not
`citest/base.schema.json`. If you need `atms_id` (or any other trip field) on an assessment event today, it can only
arrive as an ad hoc property with no schema guarantee it's present or correctly typed.
:::
