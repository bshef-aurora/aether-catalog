## Overview

Release Management owns AETHER (Aurora Event & Telemetry Hub for Enterprise Routing), the EventBridge-based
architecture that publishes CI test trip lifecycle events. AETHER is currently a **prototype** and the schema
registry, hosted here for documentation purposes, is expected to keep evolving until it reaches production.
